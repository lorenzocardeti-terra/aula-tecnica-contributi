# Proposte per Aula Tecnica
Questo repository raccoglie proposte didattiche e correzioni. Non contiene il codice
del sito e non pubblica automaticamente le lezioni. Il codice resta nel repository
privato gestito da Lorenzo Cardeti.

Usa **Issues → New issue → Proponi una lezione** oppure **Correggi una lezione**.
Non occorre essere collaboratore con accesso in scrittura: serve un account GitHub.

Leggi [la guida](CONTRIBUTING.md), [le regole](REGOLE_EDITORIALI.md) e scarica
[il kit completo](KIT_COLLEGHI.md). I modelli sono nella cartella `templates/`.

**Le proposte e gli allegati sono pubblici prima dell'approvazione. Non caricare
verifiche riservate, dati di studenti, credenziali o materiale non autorizzato.**

La preview è predisposta dal responsabile dopo una prima revisione; il solo invio
non modifica il sito. Non è richiesto un abbonamento a un assistente IA.
